# ESSim 桌面界面原型

JavaScript + React + Vite + Dockview 停靠工作台，附 Tauri 2 桌面入口。协议引擎尚未接入，现有根目录 Rust 学习工程保持不变。

```sh
cd prototype
bun install
bun run dev
bun run test
bun run build
# 安装 Rust 和当前平台 Tauri 必需工具后：
bun run tauri dev
```

浏览器预览地址为 http://127.0.0.1:1420。桌面开发使用同一份界面。当前包含基础图标，未配置发行安装包。

NovaSheet 使用 `vendor/` 中的本地构建包快照（core 0.17.3、canvas2d 0.6.6、react 0.4.14），来源为本机 `/Users/rongts/www/NovaSheet/packages/*/dist`，MIT 许可。没有更改原组件项目，也没有重新实现填充柄。更新组件时需重新生成快照并执行回归检查。

用户故事与能力边界见 [原型说明](../docs/prototype-user-stories.md)。3D GLB 仅当前会话有效；设备、通讯和显式保存的采集表使用 localStorage 保存。采集表可被多台设备引用，运行值只留在当前会话。

策略采用 CodeMirror JavaScript 编辑器与 Worker 离线执行；这是原型运行器，不是生产级脚本沙箱。详见用户故事中的运行与安全边界。

## 自定义项目文件树原型

设备工作区改为用户自定义文件夹结构。右键或树顶部加号可新建文件夹、Modbus 点表模型、Modbus 主站/从站模拟器；主从角色由入口确定。文件及文件夹支持重命名、移动与删除，非空目录和被引用的模型暂不允许删除。移动和重命名不改变稳定 ID 引用。

点表模型复用现有表格编辑器；模拟器复用设备与通讯配置页面，创建弹框配置 Modbus TCP 地址、端口、Unit ID 和模型引用。两种文件通过右键导出带版本的 JSON，模拟器导出附带引用模型。结构通过“保存项目”保存至浏览器本地工作区；配置导入、真实文件系统同步、RTU 通信与真实协议运行尚未实现。

项目文件树使用 `@pierre/trees` 的 `FileTree` / `useFileTree`，目录与文件菜单仍按原型业务配置。

首次打开及未设置目录的旧项目默认分为“点表模型”和“模拟器”两个文件夹；已有自定义目录（包括空目录结构）不会被重新分类。

项目树取消右侧文件类型文字：左侧绿色 M↓ 表示从站、蓝色 M↑ 表示主站，点表保留表格图标。模拟器右侧灰色圆点表示未启动通信，悬停展示角色与状态；原型尚无真实连接状态，不使用离线脚本运行状态替代协议连接状态。

树节点图标改为 16px 浅底 Modbus 标识，右下角箭头区分主站/从站；6px 状态点跟随名称显示，不再固定在树右侧。

树节点隐藏三点按钮，操作保留在右键菜单；模拟器最右侧使用灰色断开 Wi-Fi 图标表示原型未启动通信，悬停显示所有通讯的协议、角色、地址、端口、Unit ID 和周期。文件夹显示随展开状态切换的文件夹图标。

## 紧凑点表工作区与工具栏

点击模拟器直接打开复用 NovaSheet 的四遥运行点表，通信参数、模型引用及应用配置放在右侧紧凑属性栏，中央不再展示总览、逐行操作按钮。工具栏仅显示图标，悬停提示用途：从站为启动/停止、批量置数、恢复选区初始值、导出；主站为连接/断开、读取选区、写入选区、导出；点表模型为保存、撤销/重做、新增/删除点、JSON 导入/导出。复制粘贴保留表格快捷键及右键入口。

主站编辑控制值仅修改表格草稿，显式写入选区后才更新本地模拟对端；选区先整组校验，失败不更新运行状态。从站批量置数与恢复仅作用于选区；模型导入先替换编辑草稿，保存后更新共享模型。当前启动、连接和读写均为会话内本地模拟，不建立网络连接；RTU、真实协议互操作及系统 WebView 表格兼容性仍未验证。

全局第二行工具栏已移除；新建和保存项目位于“文件”菜单，“恢复布局”位于“视图”下拉菜单。表格自身的紧凑工具栏保持不变。
