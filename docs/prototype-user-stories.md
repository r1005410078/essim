# Dockview 桌面工作台原型

## 用户故事与布局

设备维度：创建 PCS、BMS、EMS、箱变测控、电表、温控、消防或自定义模拟设备，上传可选 3D 模型，再创建通讯。文件树为“点表库 → 采集表”和“模拟设备 → 设备 → 通讯 → 采集表引用”。PCS、BMS 默认从站，EMS 默认主站。多台设备可以引用同一张采集表，运行值按设备或主站连接分开。中间标签页随选中节点变化：采集表直接打开点表，设备是总览、设备配置和置数，通讯是总览、通信配置，主站通讯另有接收与发送。

策略维度：以脚本模拟储能策略，类似量化策略开发与回测。左侧脚本树，中间代码编辑器，右侧策略参数和教学数据绑定，底部结果曲线、日志和错误。

布局使用 Dockview，可拖动面板标签停靠、拆分、关闭和调整大小；两个工作台分别自动保存布局，可恢复默认布局。已删除旧卡片式界面实现，复用原有表格和 3D 基础组件。

## 已实现

- React + JavaScript、Tauri 2 桌面入口；Dockview 停靠布局。
- 设备创建、自定义类型、设备配置和多条通讯；采集表在点表库中编辑，通讯按协议引用采集表。配置编辑后需“保存项目”持久保存，可用 Ctrl/Cmd + S。示例工程里 PCS 01 与 PCS 02 共用一张 Modbus 表，EMS 01 作为主站按地址连接它们和 BMS 01。
- NovaSheet 采集表编辑、填充柄、撤销/重做；切换前保存采集表。多台设备共用时，保存前确认受影响的设备。由于本地组件的动态行数更新集成问题，新增点通过重建表格实现，会清空当前表格撤销历史。
- 3D 示意设备与 GLB 上传预览（内嵌资源、未压缩、最大 20 MB），模型只保留当前会话。
- CodeMirror 脚本编辑器，支持新建与修改 JavaScript 策略；Python 仅属于之前效果图的示意，原型没有 Python 执行器。
- 脚本在独立 Web Worker 中执行，5 秒超时终止，可手动停止；语法和运行错误显示在日志/错误面板。
- 简化离线模型：24 h、5 min 步长，SOC 受容量和功率影响；正功率放电、负功率充电，限制功率与 SOC 上下界。忽略效率、温度、衰减及真实功率响应，不代表真实设备物理模型。
- `on_start(ctx)`、`on_tick(ctx)`、`on_stop(ctx)`；`ctx.read`、`ctx.command`、`ctx.log`。教学点固定为 `BMS_01.SOC`、`PCS_01.实际功率` 和 `PCS_01.目标功率`，尚未绑定用户设备实例。

## 原型边界

真实协议、EMS 互操作、SQLite、模型文件持久化、Excel/CSV 文件导入、SCL、生产级脚本沙箱、可配置数据绑定和仿真时钟均未实现。脚本只应运行用户信任的本地代码；Worker 用于避免阻塞和处理超时，不是安全沙箱。Tauri CSP 为原型脚本求值开放 unsafe-eval，发布前应重新设计执行隔离与权限。

配置界面不会创建网卡或监听端口。不要把曲线和配置保存描述成真实协议测试通过。

## 验证流程

1. 从设备树打开设备、通讯和采集表引用，修改配置，保存项目并刷新。确认两台 PCS 仍指向同一张表。
2. 添加点、编辑、拖拽填充、撤销。保存被多台设备引用的采集表时确认影响范围，再保存项目。
3. 拖动 Dockview 标签形成新的面板分组，刷新验证布局，恢复默认布局。
4. 切换策略，运行默认脚本观察 SOC 和功率；修改功率或脚本后重新运行。
5. 输入语法错误或未绑定控制点，确认错误反馈；死循环应超时终止。
6. 检查多个编辑标签页切换后右侧属性、运行脚本与当前对象一致。

浏览器验收不能替代 Tauri 系统 WebView 的拖拽、粘贴、中文输入和性能验证。

## 自定义项目文件树原型

设备工作区改为用户自定义文件夹结构。右键或树顶部加号可新建文件夹、Modbus 点表模型、Modbus 主站/从站模拟器；主从角色由入口确定。文件及文件夹支持重命名、移动与删除，非空目录和被引用的模型暂不允许删除。移动和重命名不改变稳定 ID 引用。

点表模型复用现有表格编辑器；模拟器复用设备与通讯配置页面，创建弹框配置 Modbus TCP 地址、端口、Unit ID 和模型引用。两种文件通过右键导出带版本的 JSON，模拟器导出附带引用模型。结构通过“保存项目”保存至浏览器本地工作区；配置导入、真实文件系统同步、RTU 通信与真实协议运行尚未实现。

## 紧凑点表工作区与工具栏

点击模拟器直接打开复用 NovaSheet 的四遥运行点表，通信参数、模型引用及应用配置放在右侧紧凑属性栏，中央不再展示总览、逐行操作按钮。工具栏仅显示图标，悬停提示用途：从站为启动/停止、批量置数、恢复选区初始值、导出；主站为连接/断开、读取选区、写入选区、导出；点表模型为保存、撤销/重做、新增/删除点、JSON 导入/导出。复制粘贴保留表格快捷键及右键入口。

主站编辑控制值仅修改表格草稿，显式写入选区后才更新本地模拟对端；选区先整组校验，失败不更新运行状态。从站批量置数与恢复仅作用于选区；模型导入先替换编辑草稿，保存后更新共享模型。当前启动、连接和读写均为会话内本地模拟，不建立网络连接；RTU、真实协议互操作及系统 WebView 表格兼容性仍未验证。
