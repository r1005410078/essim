# 资源树目录与文档停靠接入

目录仅保存导航归属，模型、端点、Unit及应用快照继续使用稳定身份。Folder.scope为simulators或models，icon保存本地注册键，color仅接受#RRGGBB。48款SVG由本项目绘制；协议主题不代表协议已实现，未知键回退普通文件夹。

目录创建、编辑使用公共WorkbenchDialog。文件夹右键新建传父目录ID，根级新建传null。createInFolder在同一核心事务内创建资源及归属；文件夹内导入复用点表预检后提交，根级导入保留原有未保存草稿流程。

moveNavigation仅传稳定kind/id、scope和parent，不传显示路径和排序下标。核心验证全部来源、去重并去掉父子混选中的子级后原子移动，最多256个顶层对象；拒绝循环、跨分类、失效来源和失效目标。Unit、设备和内置文档不调整目录归属。

当前@pierre/trees 1.0.0-beta.6保留库的选择、键盘、排序和原生拖影；canDrop禁止库内自动移动，useNavigationDrag在捕获阶段处理dragover/drop，避免先改显示路径。成功后重投影权威目录，按稳定身份恢复选择、焦点及展开状态。没有同级排序落区。

工作区只接受本会话令牌对应的目标列表。Dockview 8.5.1的onUnhandledDragOver控制原生预览准入，onDidDrop捕获组和方向；资源先整批检查、加载，再修改布局。已有kind:id标签moveTo原实例，后续资源加入同组。grid文档组以外的导航、属性和观测边缘组不接收文档，也不作拖动来源，浮动组禁用。

各组继续共用WorkspaceStore和后台运行所有者，不创建执行器副本。实际证据与待验边界见[实施记录](../test-records/2026-10-24-resource-tree-docking.md)，浏览器组件检查不能代替原生拖动验收。

## 文件夹弹框紧凑布局

用户确认后将新建／编辑初始宽度改为440px。名称行内嵌图标预览，位置行独立，三组分类简写为协议／储能／系统并与搜索同排。图标为10列密排，只显示图形，名称由hover与可访问标签提供；颜色预设、自定义色、十六进制和选中主题名称共用一行。内部输入框去掉重复边框，外框与操作栏继续由公共Dialog维护。图标方向键按10列移动，编辑位置和名称／图标／颜色一次保存，目标排除当前目录及其后代。


## 空文档区与拖放边界补充

Dockview预览、原Tab拖动和外部树payload通过统一installDocumentDocking安装边界。中央网格已有文档时拒绝最外层edge落点，避免改变固定工具组；中央网格为空时接收根落点。创建新文档必须显式选中央文档组，网格为空时先addGroup创建中央组，不能依赖Dockview默认活动组（可能是属性边栏）。中心与四向落点继续复用同一文档实例。

同父级拖放在发命令前按顶层稳定来源检测，无变化时不发配置命令；父子同选按祖先归属判断，失效来源仍送核心校验。浏览器库集成与真实Tauri验收边界分别记录。


## 桌面壳拖放配置

窗口显式设置dragDropEnabled=false，将树与Dockview拖放交给WebView的HTML5事件。当前工作台没有原生文件拖放订阅；文件导入继续通过系统选择窗口。原因是默认Tauri/Wry原生处理器会接管macOS的拖放落区，Windows的WebView2同样要求关闭该处理器才能使用HTML5拖放。配置构建已通过，原生行为需要重启后验收，不据此宣称Windows/Linux已验证。


## 中央文档渲染与树宿主就绪

中央文档使用Dockview默认的onlyWhenVisible渲染，将既有面板内容DOM直接放在文档组。隐藏或跨组移动不销毁文档组件；不强制使用依赖动画帧定位的always overlay。组件挂载计数、未受控输入及实际业务草稿都在分屏／合并／切换后验证保留。

树事件通过attachTreeEvents在宿主就绪时立即绑定。React树包装先插入宿主，再在layout effect设置data-file-tree-virtualized；因此后备观察器同时观察宿主插入与该挂载属性，不能只观察body子节点，也不能依赖后台WebView可能暂停的requestAnimationFrame。状态层复用该入口，行变化以合并微任务同步，虚拟行回收清理自有容器。

从新建菜单进入弹框统一延迟一帧，先让菜单完成关闭与焦点恢复；与原文件夹入口一致。懒加载文档的标题可先取目录元数据，避免首次从树打开显示“配置”。测试包的acceptFirstMouse仅为原生自动化覆盖设置，未写入正式窗口配置。


树自定义菜单内容集中在TreeContextMenu处理焦点及方向键／Home／End；Enter和Space保留原生按钮执行，Tab和Esc经树库关闭并返回触发节点。执行业务操作先关闭菜单并恢复焦点，再在微任务中打开业务界面；共享弹框初始焦点不依赖动画帧，恢复焦点追踪Shadow DOM实际控件。工具栏ActionMenu为非modal下拉，已打开dialog时关闭下拉不抢焦点。
