# 点表工具栏与单元切换

正式点表采用38px单行工具栏，操作按钮只显示图标，以`aria-label`提供名称，并在hover／键盘聚焦时提示用途。Unit、模型名、配置状态和地址保留文字。窄窗口允许横向滚动，不叠加成多层工具栏。

端点配置页将原来的端点操作、单元上下文、点表编辑和覆盖操作合并。`EditorBody`通过`EditorToolbar`组合`start`、`afterSave`、`context`、`end`和`menu`，业务模块负责传入回调。端点通过`EndpointToolbarFrame`持久挂载一条共享工具栏，配置编辑器和运行控制器通过`PointToolbar`的React portal向公共操作区声明内容，不手动搬移DOM；独立模型编辑器仍渲染自己的工具栏。

- 常用：单元切换、保存实例、应用配置、新增／删除点、撤销／重做、导入／导出、配置／运行视图。
- 更多：保存端点配置、保存并预览回写、恢复全部模型配置、另存为新模型并绑定，以及查看继承／覆盖／隐藏点。
- 草稿未保存、模型变化与校验失败仍按真实结果显示；异常横幅允许占用额外空间。继承与隐藏点操作按需展开，字段说明折叠条移除，右侧字段帮助继续可用。
- 保存与应用仍为不同操作。实例保存继续走整端点校验／保存；菜单回写仍先保存并预览，不因图标化改变其影响范围。

## 单元选择

`UnitSelector`同时用于端点工具栏与右侧属性行。自定义名称显示ID徽标与名称，如`02 电池簇 B`；名称为空或等于默认`Unit 2`／`单元 2`时，只显示`Unit 02`。两位补零仅为显示，线上站号与稳定ID不变。

下拉按名称或站号筛选，保持原有顺序，勾选当前项；支持方向键、Enter、Escape和鼠标。切换只调用业务层的稳定ID选择接口，切换前提交当前编辑器缓冲到草稿，不保存、不应用、不启停。禁用单元标记为“已禁用”，仍可切换查看。长名称单行截断，通过hover查看完整名称。

## 表格密度

继续使用NovaSheet的`denseGridTheme`。移除项目的`rowHeight:28`和`headerHeight:31`覆盖，目前锁定的core 0.17.3默认均为25px。编辑表、Unit配置表与运行表共用`sheetTheme`，不以外层CSS压缩Canvas或改写组件内部绘制。

滚动条通过NovaSheet公开的`Theme.scrollbar`接入共享亮色配色，颜色统一维护在`packages/ui/src/scrollbar.css`：未悬停时使用贴近背景的浅灰滑块，hover加深，按压拖动再加深。保留原轨道宽度及最小滑块长度，通过内缩收细可见部分；横向、纵向一致。普通面板、导航与公共弹框沿用同一配色，不修改第三方包或重写滚动行为。

## 运行工具栏

TCP／RTU 主从站同样使用38px单行工具栏。`RuntimeToolbar`接收页面提供的单元、保存／应用、模型名、捕获初始值和视图切换插槽；各协议控制器保留查询、动作、忙碌状态和对话框的所有权，不搬移DOM，不改变快照、草稿提交和回验规则。

- 从站：启停、批量提交、恢复初值菜单、刷新、捕获初始值；TCP另有连接上限设置。主站：连接／断开与周期采集分别使用独立图标，保留手动读取菜单、下发、暂停／恢复当前Unit采集、设置和RTU诊断。
- 按钮统一使用`ToolbarIcon`／图标`ActionMenu`，提供hover与焦点提示；待提交数量用图标徽标显示。连接、请求、协议异常和处理时间以图标加数值显示，说明放在提示内。RTU从站不显示TCP连接统计。
- `ConfigurationStatus`区分未保存、未应用、待应用和已应用；提示说明使用已应用快照、首次运行前需保存并应用。已有快照时，待应用修改不额外阻止启动／连接。引用模型未保存的说明也进入状态提示。
- 状态点和运行状态保留文字。可靠录制等待仍直接显示；`RuntimeError`将真实错误与未确认结果单独显示为`role="alert"`，不因工具栏压缩而隐藏。
- 窄栏继续保持一行并横向滚动，键盘可聚焦末尾操作；模型名截断，地址保留可读宽度。

运行工具栏在工作台模拟器的运行视图中验证。独立预览 HTML 入口已移除；历史夹具验证见[运行工具栏实施记录](../test-records/2026-10-22-runtime-toolbar.md)，其中样例状态和命令回调不代表协议执行成功。
