# 工程文件与执行数据存储

对应[提案](../../openspec/changes/persist-project-files-and-runtime-data/proposal.md)。静态配置使用独立资源文件，运行 SQLite 不是配置数据库。工程入口固定为 `project.workspace`，其内容采用 JSON，不绑定产品名称。显示名称与虚拟文件夹由清单管理，磁盘资源以稳定 ID 的十六进制编码命名；界面不展示存储后缀。

## 打开与新建入口

正式桌面无有效工程时显示左右分区引导页，提供“打开工程”“新建工程”和最近工程列表；必须成功打开后才装配工作台。进入后顶部最左侧工程菜单与文件菜单／命令检索复用同一工程操作。打开已有工程选择 `project.workspace`，新建工程选择空目录；保留切换保护及系统文件选择窗口。

## 工程与本机状态

工程清单包含文件格式号、工程 ID、显示名称、虚拟目录、资源及附件映射、当前应用快照定位。模型、模拟器、设备和 Markdown 文档分别保存，二进制附件保持原字节。工程文件格式号不是配置历史版本；每个资源只有当前内容。`resources/applied` 是每端点唯一的当前应用定义，包括 Unit 有效模型；打开后按定义初值初始化内存值，不恢复上次实时值，不自动启动通信。

`.local/workspace.json` 是工作台布局，`.local/recovery/drafts.json` 是同一工程的聚合草稿恢复数据，不是资源清单。草稿以稳定资源 ID 关联，保存基线发生变化时保留恢复副本并报告冲突。最近工程路径在应用设置目录的 `recent-project.json`，打开失败保留原记录；明确关闭工程清空自动恢复入口但保留最近列表；引导页仍可重新打开。设置兼容旧单路径格式并最多保留十条。取消正式客户端临时会话，新建始终为空，不复制旧工程资源。

工程 Markdown 可从资源树和拼音检索打开，只读渲染复用现有组件；本轮不增加文档或附件编辑器。每次打开工程生成独立会话令牌，拒绝旧窗口迟到的布局／草稿写入，复制工程保留相同稳定 ID 也不会混写。暂缓恢复的旧草稿与后续新编辑合并暂存，不静默覆盖冲突。

## 文件写入

独占锁使用 Rust 标准库 `File::try_lock`，由打开句柄的生命周期持有；锁文件残留本身不代表被占用。资源路径禁止绝对路径、越界和符号链接。加载校验稳定 ID、引用、树循环、类别、路径及格式；外部改写时拒绝静默覆盖。

多文件事务在 `.local/transactions/files` 写变化资源的原始字节；`prepared.json` 是未决事务清单，可靠同步后原子改名为 `commit.json`。已决事务可以幂等前滚，先安装资源、最后安装工程入口，全部完成才发布成功。未决暂存丢弃。新增目录同步父目录条目；本机状态写入使用独立临时文件名，避免同时保存最近工程时互相覆盖暂存文件。备份／暂存不提供用户历史版本。进行中的工程不作为可安全复制的静态目录；先停止并完成提交。

单文件读取上限 256 MiB，附件保存上限 64 MiB；这是当前保护边界，不是规模性能结论。macOS／Unix 同步文件和目录；Windows 持久目录同步和掉电语义仍需目标平台验收，不能从 macOS 推断。

## 执行记录

后续运行的既有可靠 JSONL 写入 `runs/<运行ID>/recordings/protocol.jsonl`。独立 SQLite 投影线程消费可靠写入的字节，首次快照生成 `applied.json`，上下文写入 `context.json`。数据库保存生命周期、连接变化、错误和控制操作，原始帧继续只留 JSONL；不引入全量高频点值历史或 M07 历史／回放 UI。

SQLite 使用 `rusqlite = 0.41.0` 的 bundled 构建，连接仅在独立线程内创建和使用；不跨线程共享连接。采用 DELETE journal、FULL synchronous 和外键校验；队列上限 8 MiB／128 消息，快照与事件聚合暂存上限 32 MiB，刷新等待上限 5 秒。数据库失败只标记投影不完整，不反馈为协议故障；原有 JSONL 失败策略不改变。实际运行资源页显示独立数据库积压和错误。活动投影状态上限 4096 个；未正常结束的运行保持 `complete: false`，收到停止事件并提交后标记正常结束，保留上下文创建时间。

选型依据：[rusqlite 官方项目](https://github.com/rusqlite/rusqlite)说明 MIT 许可、bundled 构建及 SQLite 来源；[Rust File 官方文档](https://doc.rust-lang.org/std/fs/struct.File.html)说明文件锁的句柄生命周期及同步行为。当前使用本仓库 Rust 1.99.1 工具链，没有另写 unsafe 锁或 SQLite FFI。

## 验收边界

存储阶段已完成约定范围及 macOS 验收，详见[实施记录](../test-records/2026-10-24-project-persistence.md)，分别记录自动化、进程中断注入、系统文件选择和冷启动证据。Windows／Linux、网络盘、云同步并发写入和真实 EMS 不在现有证据范围内。

工程入口实现及原生验收见 [本轮记录](../test-records/2026-10-24-project-entry.md)。后端所有业务 IPC 持有当前 session 的请求租约，无工程返回 PROJECT_REQUIRED，旧请求返回 PROJECT_CHANGED，请求执行中不替换工程；核心内存测试适配仍独立保留。
