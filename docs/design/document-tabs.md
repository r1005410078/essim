# 中央文档标签：D融合样式

用户于2026-10-23确认D方案：中央文档标签栏28px，选中Tab使用内容同色底，与内容开口连通，不使用蓝色指示线；非选中Tab保持浅灰。图标14px、关闭按钮16px，水平内边距8px。「＋」使用24px命中区，紧跟最后一个Tab。

通过现有新建文档HeaderActions标记限定样式，只调整中央文档组。Dockview的空白拖动区排在操作按钮之后，保留伸展与窗口停靠交互；不把「＋」伪装成文档Tab。右侧图标标签、左侧导航及底部输出标签样式不改变。

关闭、草稿保护、新建弹框与稳定文档身份沿用原流程，不增加业务逻辑。标签滚动及溢出继续由Dockview管理，本轮没有改变其算法。

## 验证

- workbench类型检查与生产构建通过；既有大chunk提示仍存在。
- 浏览器真实工作台检查单Tab，以及打开内置Modbus指南后的双Tab：标签栏高度28px，选中box-shadow为none，「＋」左边缘与最后Tab右边缘差0px。
- 关闭指南后恢复一个Tab，「＋」仍贴在剩余Tab后。
- 本轮为局部样式及操作容器布局调整，未新增测试；未实测大量标签溢出、Tauri窗口内拖拽或带后端的新建弹框。
