# 模型与 Unit 单层覆盖

创建模拟器时，在“采集模型”中搜索已有模型，或输入名称后明确选择“新建…并绑定”。同名模型不会自动合并，已有选项显示身份以区分；取消不会创建资源。新模型、模拟器和首个 Unit 一起保存到本次会话。空模型可保存，补齐有效点表并应用后才能启动。

## 在模拟器内编辑

进入模拟器的“配置”视图，表格展示当前模型加该 Unit 差异后的有效定义。可修改点名、备注、单位、四遥分类、数据区、地址、类型、倍率、编码、默认初值、写权限及采集周期；地址以零为基准。默认初值使用工程值文本，核心精确换算原始值，非法输入整批拒绝。

顶部为单行图标工具栏，hover或键盘聚焦显示操作名称。Unit选择器可搜索名称或站号；回写、恢复、另存及“查看继承、覆盖与隐藏点”位于省略号“更多点表操作”菜单，字段来源和隐藏点恢复按需展开。配置／运行通过最右侧图标切换。

- 未覆盖字段继承模型；已保存覆盖即使与模型同值也继续保留。
- 新增点只属于当前 Unit；删除基础点表示隐藏，删除局部点则移除局部定义。
- 选中点可查看字段来源并恢复单个字段；隐藏点可以恢复。“恢复全部模型配置”清除所有差异，先形成可撤销草稿。
- 切换 Unit、配置／运行视图保留独立草稿；关闭有修改的页签可以保存、放弃或取消。
- “保存实例修改”校验并保存完整端点的配置草稿，包括各 Unit 点表；失败保留输入。

基础模型有更新时，已有未保存草稿不会被替换。可“保留编辑并重新继承”采用最新未编辑字段；若编辑点已被删除，需先处理该冲突，不能把旧点静默变成局部点。

## 回写、应用与另存

| 动作 | 保存目标 | 对运行的影响 |
| --- | --- | --- |
| 保存实例修改 | 当前 Unit 差异及端点草稿 | 不应用、不启动 |
| 保存并预览回写 | 先保存实例，再选择共享模型差异 | 展示引用范围；确认回写仍不应用 |
| 恢复模型配置 | 先修改实例草稿 | 保存后还需显式应用 |
| 另存为新模型并绑定 | 有效点表展平为独立模型，生成新点身份 | 清空源 Unit 覆盖；下次应用重新初始化，不迁移旧点值 |
| 应用配置 | 完整端点的独立有效快照 | 停止／断开整个端点，校验迁移后保持停止 |

回写只能选实际差异。涉及类型、倍率与初值等依赖字段时，需要自行选齐；系统不会扩大所选范围。其他 Unit 的显式覆盖继续保留，未覆盖字段继承新模型。所有保存引用（包括禁用 Unit）都必须合法；地址冲突、被覆盖点删除等会使整次回写失败。预览后模型、源覆盖或引用改变时，要求刷新预览。目标模型有未保存编辑草稿时，需先保存或放弃该草稿。

更换模型时有覆盖会要求明确丢弃，或先另存独立模型。复制模拟器保留差异，使用新端点、Unit 和局部点身份，不复制运行值。

## 运行值与默认初值

“运行”视图按已经应用的定义显示实际值，不用待应用倍率解释旧值。从站再次应用兼容点保留原始值；改变默认初值不会立即复位。显式复位使用已应用有效表的初值。主站初值不能当作采集结果，映射改变使旧结果失效，复位不会发送远端写入。

在运行表选中 1～1024 个点，可显式捕获确认值为默认初值。预览固定取样和时间，确认只生成配置草稿；需要另行保存、回写或应用。尚未读取、过期、不确定、等待可靠确认或映射待应用的点会使本批捕获失败；待提交置数／写入草稿不能作为取样来源。取样本身不发送读写请求。

“导出模型”导出当前 Unit **已保存的有效表**，沿用 JSON／CSV／XLSX 模型格式；不会保存继承关系，也不导出未保存草稿。

**配置仅保留本次会话，退出即丢失。** 当前没有配置历史版本或模型继承链。项目持久化留给 M08，未来项目文件须同时保留模型、稳定引用和 Unit 差异；展平模型文件不能替代项目保存。验证范围见[实施记录](test-records/2026-10-22-unit-model-overrides.md)。
