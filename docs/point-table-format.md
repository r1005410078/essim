# 点表编辑与文件交换

M02使用一个采集模型定义主从共用的点；应用到端点后按角色取用字段。四遥分类用于业务视图，Modbus数据区用于协议映射，两者独立。底部四遥标签只筛选视图，地址冲突始终按完整模型校验。

## 编辑、保存和应用

资源树右键（或Shift+F10）提供创建、打开、重命名、复制、引用查询、删除和文件交换入口。模型打开后由同一草稿承载表格与右侧属性编辑。批量粘贴／填充为一次撤销；保存生成不可变版本，不自动改变任何单元的引用或运行值。

复制选择一个已保存版本，产生新的模型及点身份。删除会重新检查配置、已应用版本和历史引用；仍有引用时禁止删除。历史引用仓储当前只有端口和测试，可靠历史落盘尚未接入。

单元选择模型版本、保存端点配置后，仍需显式应用。预览显示整组端点单元的值迁移，类型不兼容需明确恢复初值；倍率变更保留原始值并显示工程值变化。应用不自动启动。当前生产执行器未接入，不能据此发起真实采集或控制。

## 标准列

CSV首行为列名；XLSX首行为列名并在预览中选择工作表。列可在导入预览重新映射。

| 列 | 含义／取值 |
|---|---|
| id | 导出版本中的点身份；导入创建新点身份，不覆盖原点 |
| name | 点名 |
| category | measurement／indication／control／adjustment（遥测／遥信／遥控／遥调） |
| area | holding／input／coil／discrete |
| address | 零基地址0–65535；多寄存器点还须保证尾地址不越界 |
| valueType | bool、i16、u16、i32、u32、i64、u64、f32、f64 |
| byteOrder | big／little，每个16位寄存器内部字节序；Bool不适用 |
| wordOrder | big／little，多寄存器顺序／整体倒序；Bool及16位不适用 |
| scale | 非零有限十进制文本，空白默认1，允许负数；Bool固定1 |
| unit | 工程单位文本 |
| initialEngineering | 初始工程值文本；整数反算必须精确且不溢出 |
| slaveWritable | true／false；外部写入仅限可写数据区 |
| masterPeriodMs | 主站默认采集周期，毫秒 |
| note | 备注 |

JSON使用`formatVersion: 1`及完整模型定义，保留精确原始值并验证其与工程输入一致。未知版本拒绝导入。整数原始值跨IPC及文件采用十进制字符串，禁止用JavaScript Number承载64位整数。

`工程值 = 原始值 × 倍率`。例如整数点倍率0.1，12.35无法精确反算为整数，预览会拒绝并提示邻值12.3／12.4；不静默四舍五入。浮点点按目标Float32／Float64实际编码预览舍入，拒绝非有限数及溢出。

## 导入与导出边界

导入先选择文件、工作表、列映射和缺省分类，再查看可编辑预览。确认前不修改模型或目标草稿。追加按新点处理，并对追加后的完整模型检查地址占用；失败不写入任何行，成功可一次撤销。预览期间目标草稿变化会拒绝过期确认。

导出只读取选定的已保存模型版本，不导出当前未保存草稿、实例运行值、设备或端点配置。需要保留草稿时先保存模型版本，再导出。会话保存尚未落盘，退出后配置丢失；关闭及退出均有保护提示。

XLSX全部字段写为文本，精确值请在外部表格软件中也设置为文本。读入拒绝公式（即便存在缓存结果）；超过15位有效数字或绝对值≥10^15的数值单元格要求改用文本，避免接受已丢精度的数据。该检查不能恢复文件在外部软件中已损失的数字。

CSV导出对公式形态或以单引号开头的文本添加单引号，并使用附加列`__essimTextEncoding=apostrophe-v1`标识可逆转义；手工删除标识会将转义视作原文本。XLSX直接写文本，不执行公式。CSV支持UTF-8 BOM、引号及单元格换行。

当前保护限额为单文件16MiB、XLSX累计解压64MiB、数据总行数100000、XLSX最多100列及工作表矩形范围2000000格。稀疏远端单元格在分配完整矩形前拒绝。解析在后台执行并支持取消；限额是资源保护参数，不代表规模验收指标。

导出先写相邻临时文件，完整同步后替换目标；失败仅清理本次创建的临时文件。三格式往返及独立手写OpenXML／CSV夹具已验证，未宣称完成Microsoft Excel／LibreOffice所有版本互操作。
