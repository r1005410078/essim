# M01 v15 样式还原

按用户提供的v15截图调整正式工作台，保留真实配置与空态，不将示意点值、通信日志或回放记录加入生产默认目录。本轮涉及前端布局、样式、树节点显示名称和NovaSheet主题；未改协议核心或存储契约。

## 调整内容

- 冷白底色、深蓝灰文字、浅色细边框、圆角停靠区与蓝色顶线激活Tab；停靠区间距6px。
- 左栏直接显示资源／模拟器Tab及图标入口，去掉重复导航标题和默认树搜索行；树仍用`@pierre/trees`。模拟器节点显示通信方式、角色与实际地址／端口，路径到稳定业务ID映射不变。
- 文档Tab增加模型／通信图标及关闭入口、文档栏增加新建按钮；端点内部保留单行纯图标工具栏。未接入操作继续禁用并保留原因。
- 右栏采用详细信息标题、对象标题、属性搜索、单元／模型版本／所属端点／高级分类，名称和值双列对齐。保留Unit下拉和添加、设备关联、模型版本选择；关联资源的文件夹图标复用同一对象定位。
- NovaSheet继续使用既有组件与vendor，仅调整字体、行高、表头、网格线及选区色。四遥维持表内底部下划线导航，不新增表格引擎或示例点。
- 底部拆为事件记录／通信报文／运行历史Tab，以及独立运行历史停靠区；均为真实空面板，不代表历史录制和回放已交付。状态栏显示真实连接状态、无运行任务及会话存储限制。

## 边界

保留macOS原生窗口标题栏，不仿造参考图中的Windows系统按钮。参考图中的非空点表、工程值列、逐字段恢复按钮、版本差异和历史记录不因样式调整视为新增功能；当前空模型没有这些业务数据。完整点表和历史能力仍按后续提案交付，未提交Git或推送远程。

## 紧凑 Tab 跟进

- 导航、文档与底部面板 Tab 统一为30px，字体12px；收紧横向留白、图标及关闭按钮，圆角缩为3px，选中态用2px蓝色内顶线，避免切换时尺寸变化。
- 修正主题变量选择器，使其匹配 Dockview 8 的实际主题节点；原来的直接子级选择器没有覆盖内部主题默认高度。
- 独立浏览器预览在1440×900下测得全部可见 Tab 高度30px，验证“通信报文”切换成功。见[预览截图](m01/compact-tabs.jpg)。浏览器未连接Rust核心，仅验证布局与Tab切换。
- 现有11项前端测试通过。桌面包构建通过；自动审批因当前桌面会话配置可能丢失而拒绝退出应用，因此保留该窗口，本轮没有重启后的系统WebView验证。
