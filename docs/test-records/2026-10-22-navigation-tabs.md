# 左侧导航图标标签（2026-10-22）

## 实施范围

按用户确认的设计，仅调整正式工作台左侧导航：固定亮色，36px单行头部，浅灰标签底、白色浮起选中项，移除头部与底部说明的分割线。默认左栏宽度为288px，仍可由Dockview调整。

- 服务器图标为模拟器，叠层图标为资源；悬停显示中文名称，支持左右方向键、Home和End切换。
- 模拟器直接显示文件夹、端点与Unit；资源按采集模型、设备、文档分类。保留既有协议文档层级，不添加设计稿中的示例配置。
- 文件夹使用暖黄色，TCP端点与Unit蓝色，RTU端点青蓝色，模型青绿色，设备紫色，文档灰蓝色。图标沿用Lucide，树继续使用`@pierre/trees`，通过其sprite与装饰槽显示业务图标。
- 两棵树独立挂载，标签切换保留各自展开、选中状态。路径与稳定ID映射保持；设备下的单元快捷入口仍指向原端点与Unit。
- “＋”按分类提供新建／导入；模拟器文件夹与按采集点分组创建保留。批量任务、运行资源收进“更多”，原有节点右键操作保留。

## 验证

- 分组回归用例先失败，再实施导航投影：覆盖模拟器与资源隔离、文件夹内端点及Unit、设备快捷引用、模型文件夹，以及无后端仍可访问内置文档。
- `pnpm --filter @essim/workbench test`：18个测试文件、98项测试通过。
- `pnpm --filter @essim/workbench build`：TypeScript检查及Vite生产构建通过；仍有大于500kB的打包体积提示。
- macOS本地浏览器预览：确认无分割线头部、分类图标、资源顺序；折叠文档后鼠标／键盘往返切换标签，折叠状态保留；检查两个新建菜单和更多菜单；点击真实Modbus指南可打开文档及对应属性。
- 无Rust后端时新建操作禁用，模拟器显示连接等待；未注入假配置或运行值。

## 边界

本轮没有完成Tauri原生窗口复测，也没有重验真实通信、批量执行、硬件、规模或NovaSheet交互。此次只调整导航入口和展示，不改变配置保存／应用与协议运行能力，不替代此前尚待完成的原生验收。

## 菜单遮挡修正

用户反馈树节点菜单被右侧文档区域遮住。原菜单仍在树组件的插槽及Dockview面板内，依赖内部层叠环境；节点菜单和空白处菜单现通过React portal挂到`document.body`，避免祖先面板的裁切及层叠上下文。保留树组件要求的门户识别标记，使菜单点击不被误判为外部点击。

浏览器中原遮挡未稳定复现；修复后确认菜单不在Dockview祖先内、跨出左栏的右侧菜单项可命中。验证节点省略号打开、Escape关闭、文档菜单操作后关闭、Shift+F10打开空白处菜单，以及点击外部关闭。原生系统WebView仍需复测。
