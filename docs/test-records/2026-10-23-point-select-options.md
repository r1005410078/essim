# 类型、字节序与字序下拉统一

日期：2026-10-23。

## 实际变更

- 数据区、类型、字节序和字序共用 `PointSelectItem`、点表选项元数据及公共 `MarkdownTooltip`。
- 首行显示中文名称与英文标识，次行显示位宽／寄存器占用或排列含义；单元格及编辑触发器只显示中文。模型属性栏通过 `EnumSelect` 的字段参数复用相同选项。类型列由120px调整为160px以容纳中文名称。
- 类型说明覆盖 Bool、三种位宽的有符号／无符号整数和两种浮点数，列出原始整数范围、地址占用、精度及适用限制。
- 字节序显示“大端序／小端序”，解释每个16位字内部的字节排列，明确不改变Modbus单寄存器线上高字节先发的规则。字序显示“高字在前／低字在前”，分别列出32位、64位教学映射，说明64位低字在前会倒序全部四个16位字。
- 排列含义与 `crates/core/src/domain/point_table.rs` 的 `encode` 实现一致，作为ESSim应用映射约定，不宣称Modbus统一规定所有设备的多寄存器字序。
- 中文仅用于展示，原数据标识、文件格式、复制粘贴与保存契约不变。未知值仍原样显示；Bool和单寄存器类型原有字段保护保持。

## 验证

- `pnpm --filter @essim/workbench test`：29个文件、130项通过。新增检查包括全部13个类型／排列选项的中文及Markdown说明、字节序与字序区分、64位全字倒序示例、展示后复制粘贴和提交保留原始标识、撤销、非法值和空值、Bool／单寄存器字段保护、模型属性栏选中值仅中文。
- `pnpm --filter @essim/workbench build`：TypeScript与Vite构建通过，保留既有大块体积提示。
- 浏览器临时夹具挂载真实 PointGrid、DraftSource、EnumSelect 和生产样式，配置数据仅用于组件检查，无协议后端。验证：类型菜单九项、End定位双精度类型及Enter提交；字节序小端选项及说明；字序低字在前及64位说明；三列提交后仅显示中文；属性栏鼠标选择后显示“小端序”。
- 360×640视口检查类型长菜单滚动及可见项聚焦说明，浮层宽340px、左边界12px，位于视口内。菜单自动滚动时提示会按Radix基础行为关闭，重新聚焦可见项可查看说明。验证后恢复视口、关闭预览、删除临时夹具并停止开发服务。
