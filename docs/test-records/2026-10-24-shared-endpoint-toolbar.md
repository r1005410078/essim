# 配置／运行共享工具栏实施记录

用户反馈切换按钮抖动，要求一组按钮及公共工具栏。本次将端点工具栏提升为稳定挂载的共享外壳，单元选择与固定56×26px视图组始终保留，只替换中间操作内容。中间操作区独立横向滚动，切换组固定在右端。配置编辑器与运行控制器通过React portal提供操作内容，保留原回调及状态所有权；独立模型编辑器继续使用自己的工具栏。

验证：

- `pnpm --filter @essim/workbench test`：34个文件、148项测试通过。新增静态渲染回归覆盖两种模式只提供一个工具栏和一组切换、选中与键盘焦点语义，以及独立模型编辑器工具栏。
- `pnpm --filter @essim/workbench build`：类型检查与生产构建通过；保留已有大包体积提示。
- `git diff --check`：通过。

边界：静态渲染不验证portal挂载后的DOM位置及屏幕坐标，尚未在真实Tauri窗口复核切换抖动、窄窗口操作区滚动及方向键交互，不将上述测试视作原生交互验收。不改变后端通信与保存／应用语义。
