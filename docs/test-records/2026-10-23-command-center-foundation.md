# 顶部检索基础重构验证

日期：2026-10-23。

本轮仅建立资源索引与命令路由基础，未还原标题栏、检索面板或历史导航设计。

## 已实现

- 复用导航投影建立资源索引，中文／英文、拼音全拼、首字母及路径检索，同名身份保留，目录更新，固定返回上限；拼音库按首次查询动态加载。
- 轻量命令注册、描述检索、可用状态、执行时校验、注销与错误传递；六条真实工作台命令。原有新建及工具菜单已走统一路由。
- App上下文提供两个查询入口与命令执行入口，资源结果继续复用既有Target导航。

## 验证

- `pnpm --filter @essim/workbench test`：30个文件、136项通过。新增6项覆盖命令重复注册、条件拒绝、注销、元数据搜索、真实业务回调路由、异步错误，以及中文／全拼／首字母／英文混合／路径、同名身份、重命名与删除、数量限制和前导命令符。
- `pnpm --filter @essim/workbench build`：TypeScript与Vite构建通过，索引及拼音库形成独立异步块。原有应用大块体积提示仍存在，不据此声称整体构建优化完成。
- 公开依赖pinyin-pro固定3.29.5，确认MIT许可；通过固定完整性和tarball地址按冻结锁文件安装。最初直接pnpm add触发私有NovaSheet包404，最终未改变私有包版本或注册源。
