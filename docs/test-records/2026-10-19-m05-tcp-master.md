# M05 TCP主站首阶段

日期：2026-10-19。对应[提案](../../openspec/changes/implement-modbus-tcp-master-runtime/proposal.md)、[实施任务](../../openspec/changes/implement-modbus-tcp-master-runtime/tasks.md)。

## 已接入范围

- TCP单目标、多Unit共享连接；各Unit独立引用已应用模型。连接／采集／停止采集／断开分开，支持暂停单个Unit的周期采集。
- 复用libmodbus同步四区主站API，完整点按Unit／区域／周期合并连续请求，不跨地址空洞、不拆多寄存器点；读位2000／寄存器125，写位1968／寄存器123。
- 周期按实际完成后推进到期时间，不补积压轮次；手动批次优先，写入与回验间不穿插轮询。一个连接至多一个手动批次，其他目标独立所有者。
- 当前Unit全部遥控／遥调待写草稿显式下发，整批预校验；逐块写入及回验，失败停止余项，不回滚已执行块，不自动重发。协议拒绝、结果不确定、未执行、协议确认和回验结果分别显示。
- 按点保存最近成功原始值、Unix毫秒时间、质量和错误。失败不清除旧值或时间；默认3倍周期过期。停止采集／断开有独立提示。
- 默认连接3000ms、请求1000ms、重连3000ms，可在主站设置修改，进入配置草稿，保存并应用后生效。后端校验超时10～30000ms、重连100～60000ms、过期倍数1～100。
- 保存不改变运行；应用先校验、取消余项并等待当前同步请求完成／超时、确认释放，再替换快照。保持断开；来源及解释兼容的缓存保留并标记待重读，变化点清空。待写草稿必须取消应用或明确丢弃。
- 采集中断线重连，恢复后继续读取；仅手动连接时不自动重连。主动断开取消重连，停止采集保留现有连接。
- 真实字节来自私有Unix通道与TCP透传桥，libmodbus负责编码与确认校验。主站TX为请求、RX为响应，解析与请求关联按角色适配。
- 连接前建立自包含JSONL快照；起始读取缓存与模型分开记录。操作意图及完整帧在后续发送前同步记录，记录失败停止受影响连接。重连不另开运行文件；最近观测不代替完整文件或可用回放。

## 资源与证据边界

首版最多32个主站所有者槽；每槽一个所有者线程，连接后一个透传线程，手动队列容量1，桥每方向待发送队列最多4096字节。单批下发最多1024个完整点，查询最多1024点、最近观测100条，前端累计窗口最多500条。这些是工程门禁，不是32实例持续性能验收。

当前只验证macOS软件路径。复用已有libmodbus上游的响应校验／超时边界，不宣称严格协议防火墙、整次操作硬实时期限、Linux／Windows、真实设备动作或真实EMS兼容。官方依据：[响应超时](https://libmodbus.org/reference/modbus_set_response_timeout/)、[寄存器读取](https://libmodbus.org/reference/modbus_read_registers/)。

## 独立互操作

入口：`cargo build -p essim-infrastructure --features tcp-runtime,vendored --example tcp_master --offline`，随后 `python3 scripts/verify_tcp_master_runtime.py`。

独立从站为PyModbus3.11.3，脚本创建随机回环端口和临时运行目录。两个Unit各16个点，四区教学零基100～103；holding初值分别7／14，input分别9／18。验证8功能码、各Unit值独立、停止采集无积压、单Unit暂停隔离、停服后重连恢复及可靠文件连续记录。环境、实际请求与帧数见[机器结果](assets/m05/interop.json)。该脚本为短时行为互操作，不是持续负载或规模报告。

## 原生工作台

独立`ESSim M05 Check.app`，macOS系统WebView；独立PyModbus从站监听127.0.0.1:15327，使用16点CSV教学模型。

1. 导入并保存模型，新建TCP主站，显式应用后连接。连接成功时请求数仍为0，确认未自动采集。
2. 开始采集后，input[100～103]显示真实值9和有效质量；停止采集后保留连接，请求数保持457。
3. 在遥调页将holding[100]待发值设为42，显式下发后请求数增加2（写入＋回验），最近读取值42，显示“协议已确认，回验一致”，待写数量归零；[回验截图](assets/m05/readback.png)。
4. 主站RX真实响应按响应解码，显示FC02及读位数据；窗口缺少匹配请求时明确提示地址／实际位数未知；[响应解析](assets/m05/response-parse.png)。
5. 修改请求超时至1200ms，写入草稿并保存，连接及运行快照保持。再编辑一项待写值50，应用弹窗在未确认丢弃时禁用提交；[草稿保护](assets/m05/apply-draft-guard.png)。
6. 明确丢弃测试草稿并应用后，显示未连接、采集已停止、下发修改0；[应用后断开](assets/m05/applied-disconnected.png)。该值50未下发。
7. 退出独立可丢弃测试会话并停止独立PyModbus服务，未操作用户其他模拟器。
