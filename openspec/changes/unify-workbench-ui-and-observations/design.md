## Context
正式 React/Dockview 客户端已接入 TCP 从站；运行表能显示真实值，底部观测面板尚未使用后端事件。参考图位于 docs/design/ui-workbench-v2，仅为布局示意。

## Goals / Non-Goals
**Goals:** 配置与运行信息分层、操作文字清楚、真实观测可排障、紧凑布局。
**Non-Goals:** 修改 NovaSheet 主题、编辑器、选区、滚动或填充柄；新增协议、持久化和录制回放。

## Decisions
- 外围组件使用现有 shadcn 组件与统一样式；保持 Dockview 和已访问表格挂载策略。
- 观测来自可靠记录投影，附带序号和采集时间；准备响应与成功发送分开，不能伪造 TX 成功。
- 当前端点按需查询，缓存有界、去重，暂停只冻结观测展示；不影响仿真运行。
- 保存／应用仍经现有应用服务；预览显示完整端点迁移范围，应用后保持停止。

## Risks / Trade-offs
- 高频通信只展示有界最近记录 → 明示窗口范围，导出当前视图，不能当完整抓包。
- 小窗口操作拥挤 → 工具栏不折行、次要动作放折叠菜单，允许横向滚动。
- 原生 WebView 行为差异 → 构建及原生验证，保留验证边界。
