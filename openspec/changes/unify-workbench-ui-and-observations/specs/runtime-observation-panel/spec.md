## ADDED Requirements

### Requirement: 真实观测
观测面板 SHALL 展示实际运行记录，区分接收、响应准备与发送确认，并支持筛选、暂停展示和当前视图导出。

#### Scenario: 批量写入
- **WHEN** 独立客户端发送写请求并收到响应
- **THEN** 面板显示真实 RX 字节、响应字节与发送确认，不将准备响应当成已发送

### Requirement: 有界查询
观测 SHALL 使用稳定序号去重并限制缓存，在无数据和查询失败时明确提示。

#### Scenario: 重复轮询
- **WHEN** 后端多次返回同一批最近记录
- **THEN** 前端不会重复添加，暂停展示不会停止端点运行
