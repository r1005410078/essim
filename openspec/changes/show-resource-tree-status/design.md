## Context

ProjectNavigation使用@pierre/trees 1.0.0-beta.6，Shadow DOM装饰槽已显示业务图标，React仅提供菜单和头部槽。现有主从站查询允许unit:null、points:[]读取元数据。

## Goals / Non-Goals

Goals：最右侧固定图标区、真实运行反馈、hover说明、配置与运行状态独立；其他布局不变。
Non-Goals：不新增通信动作、全量点值查询、在线推断、健康度后端接口，不将未观测Unit标为异常或在线。

## Decisions

- 保留原树及左侧装饰。通过公开getFileTreeContainer访问已渲染行，仅追加自有状态容器，React portal渲染图标和共享Tooltip。MutationObserver跟随虚拟行变更，卸载清理，不改树数据或第三方包。依赖锁定版本的data-item-path，记录兼容性风险。
- 最右侧图标12px，间距4px；预留配置标记并排，名称允许截断，状态不收缩。运行状态使用绿／蓝／灰／红，待应用与数据过期用琥珀色。
- 每秒查询当前实际渲染节点对应端点，最多4个并发，points为空。隐藏导航停止轮询；代次、工作区序号及删除检查阻止失效响应提交。失败显示状态未知并保留错误说明，不继续绿色。
- 端点显示运行状态；Unit显示已禁用、主站采集暂停／采集中及已观察数据质量异常，从站正常Unit不复制端点状态。未保存蓝点和待应用时钟独立于运行。
- 已观察质量记录由现有主站点查询提供，带工作区序号，序号改变即不采用；只表示已观察点的失败／过期，不宣称全Unit健康。

## Risks / Trade-offs

- Shadow DOM虚拟行被复用 → 挂载层按元素和路径同步、移除失效容器，不重建树模型，实际浏览器验证。
- 查询与配置变更竞争 → 丢弃过时代次／序号响应，元数据轮询不写业务配置。
- 元数据不含全Unit质量 → 仅展示真实已观察异常，hover明确范围。
- 真实Tauri未复核 → 验证记录明确边界，不以静态测试代替交互验收。
