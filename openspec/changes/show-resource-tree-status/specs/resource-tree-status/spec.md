## ADDED Requirements

### Requirement: 右侧状态图标
系统SHALL在树节点行最右侧显示彩色状态图标，保留名称、展开、选择及菜单布局，hover提供状态和真实原因。

#### Scenario: 并列状态
- **WHEN** TCP从站监听且存在待应用修改
- **THEN** 最右侧同时显示绿色监听图标与琥珀色时钟，不显示行内状态文字。

### Requirement: 状态真实性
系统SHALL依据真实主从站元数据及已观察质量展示状态，不能将监听视为Unit在线。

#### Scenario: 从站Unit
- **WHEN** 父端点监听且Unit启用
- **THEN** Unit不继承监听或在线标记，禁用时独立显示禁用图标。

#### Scenario: 主站Unit
- **WHEN** 主站周期采集且Unit暂停
- **THEN** Unit显示暂停，不显示采集中；已观察点过期或失败时以警示说明观测范围。

#### Scenario: 查询失败
- **WHEN** 元数据查询失败或响应已失效
- **THEN** 不提交过期响应、不伪造运行正常，查询失败提供状态未知及原因。

### Requirement: 有界元数据查询
系统SHALL只轮询实际渲染树行对应端点的元数据，不读取点值，不触发协议动作，关闭导航后停止轮询并清理资源。

#### Scenario: 隐藏或删除
- **WHEN** 导航隐藏或端点删除
- **THEN** 停止对应查询并忽略其在途响应，树选择和展开状态保留。
