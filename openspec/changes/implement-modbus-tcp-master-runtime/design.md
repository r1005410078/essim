## Context

用户逐项确认TCP先行，连接／采集分开、共享连接多Unit、周期分组、三倍过期、整批预校验及逐请求结果、手动优先、写入不重试、显式应用断开。现有ModbusClient为线程绑定同步C句柄，遇非协议异常主动关闭；官方响应超时并非完整操作墙钟期限。

## Goals / Non-Goals

交付真实TCP主站闭环及独立测试；不交付RTU、配置数据库、完整历史回放或千实例主站性能承诺。原M04／M02／M03待验项不因此完成。

## Decisions

- core/master负责纯分组／编码规划与运行参数；commands/master、events/master、queries/master分别承载意图、事实及质量投影。infrastructure/tcp_master负责连接所有者、调度及事件观测，Tauri无业务规则。
- 每端点独立所有者线程、最多32个主站运行槽，手动队列容量1。同步libmodbus句柄只在所属线程创建／销毁，一个慢目标不会阻塞其他目标。先给明确资源边界，不把从站固定线程方案硬套同步主站。
- 真实字节观测使用私有Unix socket pair与有界透传桥，libmodbus继续编码和校验请求响应，不改vendored源码、不重写协议栈。桥额外一条线程，记录实际转发字节，按MBAP完整帧生成观测；分段／合并与非法长度单测覆盖。桥只服务本连接，无应用层自动重发。
- 默认连接3000ms、请求1000ms、重连3000ms、过期倍数3；参数作为当前端点主站运行设置，保存进会话配置，不增加配置版本。限时范围及资源边界由后端校验。
- 周期任务按完整请求块调度，截止时间以实际执行后当前时间推进，不积压；手动一批请求及回验期间不插入周期读取。停止／断开设置取消标记，至多等待当前同步请求超时；剩余未发出项标记未执行。
- 查询读取快照不等待网络；只返回指定的最多1024点及最近100条观测。保留最近成功值和时间，质量独立，失败优先于过期；断开／停止采集有独立状态提示。
- 配置应用先校验再取得端点操作门、断开／取消采集并等待资源回收，再原子提交快照；主站保留同点身份且区域／地址／类型／字节序／字序／倍率相同的缓存，重新读取前标记过期。前端待写草稿明确丢弃后应用，失败不混入新配置。

## Risks / Trade-offs

- 同步库响应校验及超时边界 → 限制参数、有界手动操作、关闭失效通道，记录实际限制，不宣称硬实时或完整防火墙。
- 多请求写入无法事务回滚 → 逐点结果区分确认／回验／拒绝／不确定／未执行，失败停批且禁止自动重发。
- 双线程每端点成本 → 首批上限32，不宣称大规模；M06依据实测另行优化。
- 原生验证受锁屏影响 → 真实GUI与独立工具证据分开，未验项保留。
