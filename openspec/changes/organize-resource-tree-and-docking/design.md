## Context

正式客户端采用Dockview 8.5.1和@pierre/trees 1.0.0-beta.6。ProjectNavigation目前关闭dragAndDrop，选择末项就打开文档；导航弹框已有文件夹创建、移动、重命名，但Folder仅含id/name/parent。核心有saveFolder、moveEndpoint和modelMembers，缺少模型移动与跨对象原子批量移动命令。当前open按kind:id定位唯一Tab并激活，不接受指定目标组／方向。

用户已确认七项交互及[48款图标选型图](assets/icon-concepts.png)。图片仅为视觉参考，正式图标必须制作本地SVG，不把生成位图直接塞入16px树节点。

## Goals / Non-Goals

Goals：按目录新建；目录图标与颜色；多选拖拽换层级而不排序；中央Tab分屏；树资源按Dockview落点打开；保持共享状态、稳定身份、已有布局和右侧状态图标。

Non-Goals：不新增任意文件系统／任意类型编辑器；不移动内置只读协议文档或固定根分组；不改变Unit所属端点、设备关联和协议映射；不引入配置版本、持久化、系统窗口间拖拽或独立弹出窗口。协议主题图标不是协议能力开关。

## Decisions

### 1. 目录范围与身份

本轮可组织对象为模拟器分支的端点和采集模型分支的模型资源。内置文档可拖入工作区阅读，但不改目录归属；设备根与设备对象不转化为可任意迁移的文件。文件夹支持任意上述主题，不绑定实际协议或设备类型。

Folder增加有默认值的scope（simulators/models）、icon和color，继续用稳定FolderId。父子目录必须同scope，端点／模型只能进入对应scope目录；根目录由scope+null表达。这样避免同一空文件夹同时出现在两个分类，也不混淆右键新建类型。名称可重复，路径展示保留既有去歧义规则；不能以显示名称作为移动身份。

旧数据默认普通文件夹、默认蓝色，旧scope缺省归模拟器分支。若旧modelMembers引用这些目录，为模型分支生成等价目录映射，保留祖先结构与显示名称；原目录ID留在模拟器分支，模型资源ID及引用均不变。共享目录兼容归一化在克隆目录中完成并校验后一次替换，不修改协议配置，不建设版本迁移框架。当前仅会话配置，新增字段不宣称具备磁盘保存。

### 2. 图标与颜色

新增有限的图标注册表，以稳定字符串键存储，不保存任意SVG／HTML。48款预设分组如下：

| 编号 | 预设 |
| --- | --- |
| 01—08 | 普通文件夹、项目文件夹、Modbus TCP、Modbus RTU、IEC 104、IEC 61850、MMS、GOOSE |
| 09—16 | SV、OPC UA、MQTT、DNP3、CAN、BACnet、DL/T 645、自定义协议 |
| 17—24 | 储能电站、储能集装箱、电池舱、电池柜、电池簇、电池模组、电芯、BMS |
| 25—32 | PCS、EMS、电表、变压器、开关柜、直流汇流箱、断路器、母线 |
| 33—40 | 光伏阵列、风机、电网、交流负载、充电桩、液冷系统、消防系统、温度传感器 |
| 41—48 | 网关、交换机、串口服务器、采集点表、遥测、遥信、遥控、遥调 |

协议／项目预设为文件夹＋徽记，设备／系统预设为主题轮廓，可用作文件夹身份图标；资源类型与可接受内容由scope决定。16／20px使用统一细线与简化细节，协议全名放在选择器和tooltip，不能依赖缩小后不可辨认的字样。统一来源许可注释，能够独立改色。

预设色蓝、青绿、琥珀、紫、灰；自定义只接受#RRGGBB。颜色只用于节点主体图标，不改变运行状态图标的既有颜色。新建与“编辑文件夹”共用WorkbenchDialog，含名称、目标目录、图标分组选择、颜色及实时预览；保留文字可访问名称、方向键、Enter和Esc。未知旧图标降级普通文件夹，不丢内容。

### 3. 右键创建与提交

创建入口携带{scope,parentId}，打开弹框时捕获，不随之后的树选择变化。模拟器文件夹菜单提供新建模拟器／子文件夹；模型目录提供新建模型／导入模型／子文件夹。根级菜单传null；顶部新建沿用明确的根级目标，不悄悄使用上次选中目录。

新建业务对象及所属目录在一个核心命令中校验、提交并发布结果；不采用“先创建、再移动”留下半成品。创建期间目标目录被删则整体失败，弹框保留输入；取消不产生对象或目录。复用原有业务创建、导入校验，不另开一套同类流程。

### 4. 树内选择与移动

Ctrl／Cmd多选、Shift范围选择；普通单击沿用打开，增减选择和拖拽起手不依次打开全部选中项。拖拽未选中项只携带该项，拖拽已选项携带当前选中集。父文件夹和其后代同时选中时，提交前只保留顶层项，避免把后代拆出。

拖放只命中目录内部或显式根级落区，不显示同级前后插入线；目录可悬停展开。落在普通文件或Unit上不可作为父级；端点行仍可能是树组件的directory，不能据组件isDirectory就允许业务落入端点。跨scope、Unit重归属、内置只读节点、拖到自身／后代全部拒绝。同层仍沿用既有目录优先及名称排序。

新增有界批量导航移动命令（最多256个去重后的顶层对象，超限整体拒绝并提示）。包含类型、稳定ID、scope、目标父ID，由核心对克隆导航树整体检查存在性、scope、循环及全部源，成功一次提交，失败零变更；同父级移动为无副作用操作。拖动目录保持所有后代归属不变；不会保存点表草稿、重应用或重启通信。

树库的onDropComplete在视图路径变更后通知，不足以承担业务事务。使用隔离拖放适配器处理原生drop并阻止库先改业务路径，复用其选择、拖影及canDrag/canDrop能力；成功后由权威目录投影刷新路径。若版本限制必须先做视图预览，失败恢复完整路径、展开与选择快照。实施前用当前库验证事件顺序，不重写树组件。

### 5. 两类拖拽分流

内部payload只包含会话标记、节点类型、稳定ID和来源scope，不依赖中文显示路径，也不接受任意外部文本作为业务命令。树内目标解释为原子移动，Dockview目标解释为打开／定位。文件夹或Unit不作为可停靠文档；混合选择含不可打开对象时，工作区不接受整次拖放，不能悄悄只处理部分项。

多个可打开资源同时落入工作区时，在选定落点建立一个目标组，按当前树顺序加入Tab，不为每项建立一块分屏；树归属保持不变。取消、拖出窗口或非法目标均不修改目录、文档组或资源。

### 6. Dockview分屏与共享状态

使用已安装Dockview的onUnhandledDragOver、onWillDrop/onDidDrop及panel/group定位API接入外部树拖拽；原生DragEvent与PointerEvent分支先缩窄类型再读取dataTransfer。中心加入目标组，左右上下新建相邻中央文档组；空工作区可建立首组。边缘预览使用Dockview本身，不能手写一套不一致的分屏算法。

已打开文档保持kind:id唯一：落在其他组时移动原Tab并激活，不创建第二份资源视图或协议实例；落在同组只激活，不产生空组。新增打开先验证目标资源仍存在、加载成功和落点仍有效，再提交布局；失败不遗留空分屏。批量拖入先预检全部目标，失败保留原布局。

Tree/Open/命令检索/历史导航统一走文档定位服务，默认打开位置仍遵循现有规则。所有组复用WorkspaceStore、模型／Unit草稿和端点执行器，移动Tab不卸载后台任务或重复轮询；右侧属性跟随活动文档，保存快捷键只作用于当前文档。重命名和树层级变化不改变Tab身份。

仅开放中央文档组之间的分屏与合并，左导航、右属性、底部观测仍为已有固定边缘组。Tab边缘拖放不能将文档塞进这些工具组，工具组也不变为文档；保留现有面板开关、最小尺寸、Tab样式、状态显示、关闭保护及窗口拖动区域。布局变更只保留本次会话。

## Risks / Trade-offs

- 树虚拟化、Shadow DOM和状态挂载层同时工作 → 测试多选、滚动、拖放重绘与状态图标无重复，必要适配隔离在导航边界。
- Dockview默认开启拖拽不等于已完成业务分屏 → 明确文档组白名单、外部payload和落点路由，验证当前8.5.1实际事件。
- 批量移动与目录删除竞争 → 核心原子检查，不仅靠前端canDrop；接口错误保留用户选择与草稿。
- 48款图标密度较高 → 分组选择、名称检索与当前预览，保证16px辨识度，避免额外通用主题平台。
- 目录归一化影响旧modelMembers → 覆盖空目录、纯模型、纯模拟器及共享祖先用例，保留业务ID与路径含义。
- 系统WebView拖放差异 → macOS Tauri为首轮原生验收；Windows/Linux单独列证据，浏览器通过不能替代原生拖拽。

## Migration Plan

先补核心目录字段／事务测试和向后兼容读入，再接上下文创建与SVG预设，随后树内多选移动，最后统一文档定位并接Dockview。关闭新拖放适配可回退菜单移动，既有对象与保存格式不引入版本功能。记录实际完成项及未验平台，不把图标选型或提案校验当作实现完成。

## Open Questions

无阻塞产品决策。实施第一步需核实已安装库对多选拖影、拖出Shadow DOM及文档组限制的真实行为；若只能通过重大重写才能达成，先更新本设计说明与任务，再调整实现。

## 文件夹弹框紧凑版（用户确认）

新建与编辑共用440px初始宽度的WorkbenchDialog，继续由公共组件管理标题栏、滚动、操作栏、拖动与缩放。内容改为名称内嵌18px图标预览、位置一行、分类与检索同一工具行、10列30px密排图标和单行颜色控件。图标保留悬停名称与可访问标签，不增加常驻图标文字；图标键盘上下移动按10列计算。编辑时位置可与名称、样式一起原子保存，父级选项排除自身与后代。子目录新建名称保持“新建文件夹”，不误取父级名称；根级编辑位置保持null。菜单新建在关闭菜单后下一帧打开，确保名称自动聚焦。
