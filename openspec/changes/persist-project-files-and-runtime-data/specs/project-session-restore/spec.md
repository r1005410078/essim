## ADDED Requirements

### Requirement: 启动恢复最近工程

系统 SHALL 在成功打开工程后记录其入口路径，下一次启动恢复工程及可用布局，不启动任何协议通信。

#### Scenario: 正常冷启动

- **WHEN** 最近工程有效且未占用
- **THEN** 加载已保存资源和可恢复的 Tab 分屏，所有端点停止

#### Scenario: 恢复失败

- **WHEN** 最近入口不存在、损坏或被占用
- **THEN** 展示原因和新建／打开入口，保留原最近路径，不创建替代空工程

### Requirement: 草稿与布局隔离

系统 SHALL 将本机布局和恢复草稿保存在 .local，草稿不得自动覆盖已保存资源。

#### Scenario: 崩溃后恢复

- **WHEN** 启动发现未保存草稿
- **THEN** 允许恢复或丢弃；源文件变化时提示冲突并保留恢复内容

#### Scenario: 布局失效

- **WHEN** 布局包含已删除资源或结构损坏
- **THEN** 过滤无效项或使用默认布局，已保存配置不受影响

### Requirement: 工程生命周期保护

系统 MUST 在切换或关闭工程时处理脏草稿、停止通信并刷新执行记录，目标加载失败不得丢失当前工程。

#### Scenario: 取消切换

- **WHEN** 用户在保存保护或运行停止确认中取消
- **THEN** 仍保留当前工程及草稿，不更新最近路径

#### Scenario: 目标加载失败

- **WHEN** 目标预检或加载失败
- **THEN** 不切换到空工程，不覆盖当前配置，已停止的通信不自动恢复
