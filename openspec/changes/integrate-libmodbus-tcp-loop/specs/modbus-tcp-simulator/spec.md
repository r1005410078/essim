## ADDED Requirements

### Requirement: 教学 SOC 映射与真实读取
系统 SHALL 提供单个 Modbus TCP 从站，默认绑定 127.0.0.1:1502，支持配置 IPv4/端口；教学 SOC 使用稳定点 ID `soc`、Holding Registers 零起始地址 100、UInt16 单寄存器、倍率 0.1%，初始原始值 650。系统 MUST 标明其为教学映射；当前只支持 Unit ID 1、FC03。

#### Scenario: 独立客户端读取初始 SOC
- **WHEN** 实例监听成功，独立客户端发送 `00 01 00 00 00 06 01 03 00 64 00 01`
- **THEN** 系统返回 `00 01 00 00 00 05 01 03 02 02 8A`，工程值为 65.0%，事务号正确回显

#### Scenario: 其他 Unit ID 不被误路由
- **WHEN** 已校验的请求 Unit ID 不是 1
- **THEN** 系统关闭当前客户端连接并记录原因，SOC 不变，监听仍可接受后续连接

### Requirement: 运行值更新与初始值隔离
系统 SHALL 通过核心应用接口更新 SOC 原始整数，仅接受 0–1000，使用实例 ID 与点 ID 定位。更新确认 MUST 在运行值与寄存器映射更新后返回；运行值更新 MUST NOT 修改教学模型初始值。停止后重新启动 SHALL 保留本会话运行值，程序新会话 SHALL 从 650 开始。

#### Scenario: 更新确认后外部读回新值
- **WHEN** SOC 更新为 700 并已收到更新确认，独立客户端再次有效读取
- **THEN** 响应原始值为 700，工作台工程值为 70.0%，初始值仍为 650

#### Scenario: 拒绝无效 SOC
- **WHEN** 更新值为负数、1001、非整数，或者实例/点 ID 不存在
- **THEN** 返回有错误码及定位信息的失败，运行值与映射保持不变

#### Scenario: 本会话重启保留运行值
- **WHEN** SOC 已更新为 700，实例停止后在同一应用会话重新启动
- **THEN** 外部读取仍返回 700，不把停止隐式解释为恢复初值

### Requirement: 只读访问与协议异常
系统 MUST 在完整有效请求上限制支持范围，不得无条件开放库默认写功能。有效 FC03 地址越界 SHALL 返回异常 02，数量 0 或超过 125 SHALL 返回异常 03；FC06/FC16 写入教学 SOC SHALL 返回异常 02，其他有效但未支持功能 SHALL 返回异常 01。拒绝请求 MUST NOT 修改运行值。

#### Scenario: 读取非法地址
- **WHEN** 客户端使用 FC03 读取地址 101、数量 1
- **THEN** 返回功能码 0x83、异常码 0x02，SOC 不变，连接可继续有效读取

#### Scenario: 非法读取数量
- **WHEN** 完整 FC03 请求的数量为 0 或 126
- **THEN** 返回功能码 0x83、异常码 0x03，不越界访问寄存器映射

#### Scenario: 写入只读 SOC
- **WHEN** 客户端以合法 FC06 或 FC16 请求写入 SOC
- **THEN** 返回对应异常功能码与异常码 0x02，后续读取值保持不变

#### Scenario: 未支持功能
- **WHEN** 客户端发送完整有效的 FC04 请求
- **THEN** 返回功能码 0x84、异常码 0x01，不将其当作 Holding Registers 读取

### Requirement: 实例生命周期与客户端隔离
系统 SHALL 实现 Stopped、Starting、Listening、Stopping、Failed 状态，真实绑定监听完成才报告启动成功；状态 SHALL 分开表示监听与活跃客户端连接数。首版最多服务一个活跃客户端。断连或非法客户端 SHALL 不终止监听；停止 SHALL 幂等，完成后监听端口与客户端资源释放。

#### Scenario: 端口占用导致启动失败
- **WHEN** 指定端口已被占用
- **THEN** 启动返回明确错误，状态为 Failed，不报告 Listening，不泄漏启动中已申请资源

#### Scenario: 重复启动与重复停止
- **WHEN** Listening 状态重复启动，随后重复停止
- **THEN** 重复启动返回 AlreadyRunning，第一次停止收回资源，后续停止成功且无重复释放

#### Scenario: 断连后重新连接
- **WHEN** 当前客户端断开后，新客户端连接并读取教学 SOC
- **THEN** 实例保持监听，新连接可读取当前值，旧连接的半帧或请求不污染新连接

#### Scenario: 有活跃客户端时额外连接
- **WHEN** 已有一个活跃客户端，另一个客户端尝试接入
- **THEN** 额外连接被明确拒绝或关闭，不能接管当前上下文，原客户端仍能有效读取
