## valueType.bool
### 布尔量
`bool` · 1 位，1 个位地址

表示 `true`／`false`，用于线圈或离散输入，不占用16位寄存器地址。

字节序和字序不适用，统一保留 `big`；倍率固定为 `1`。

## valueType.i16
### 16 位有符号整数
`i16` · 16 位，1 个寄存器

原始值范围：**−32768～32767**，可表示正负整数。

字节序控制该寄存器内部的两个字节；字序不适用，使用 `big`。

## valueType.u16
### 16 位无符号整数
`u16` · 16 位，1 个寄存器

原始值范围：**0～65535**，只表示非负整数。

字节序控制该寄存器内部的两个字节；字序不适用，使用 `big`。

## valueType.i32
### 32 位有符号整数
`i32` · 32 位，2 个连续寄存器

原始值范围：**−2147483648～2147483647**，可表示正负整数。

字节序作用于每个16位字内部，字序作用于两个16位字的排列。按设备点表确认这两项。

## valueType.u32
### 32 位无符号整数
`u32` · 32 位，2 个连续寄存器

原始值范围：**0～4294967295**，只表示非负整数。

字节序作用于每个16位字内部，字序作用于两个16位字的排列。按设备点表确认这两项。

## valueType.i64
### 64 位有符号整数
`i64` · 64 位，4 个连续寄存器

原始值范围：**−9223372036854775808～9223372036854775807**。

64位整数按精确文本传递，不经 JavaScript Number 转换，避免超过安全整数范围时丢失精度。字序作用于全部四个16位字。

## valueType.u64
### 64 位无符号整数
`u64` · 64 位，4 个连续寄存器

原始值范围：**0～18446744073709551615**。

64位整数按精确文本传递，不经 JavaScript Number 转换，避免超过安全整数范围时丢失精度。字序作用于全部四个16位字。

## valueType.f32
### 32 位单精度浮点数
`f32` · 32 位，2 个连续寄存器

采用 **IEEE 754 单精度**，适合带小数的测量值，但不能精确表示所有十进制小数。

工程值反算允许目标精度的正常舍入，溢出或非有限值会被拒绝。按设备点表确认字节序和字序。

## valueType.f64
### 64 位双精度浮点数
`f64` · 64 位，4 个连续寄存器

采用 **IEEE 754 双精度**，精度高于单精度，但仍不能精确表示所有十进制小数。

仅接受有限值，不接受 NaN 或无穷大。按设备点表确认字节序和字序；字序作用于全部四个16位字。

## byteOrder.big
### 大端序
`big` · 每个16位字内，高字节在前

教学示例 `0x1234`：字节排列为 **`12 34`**。

这是 ESSim 的应用数值映射。Modbus 单寄存器在线上传输仍按高字节先发，选择字节序不会修改协议的帧格式。

Bool 不适用，固定保留 `big`。应按设备手册确认映射方式。

## byteOrder.little
### 小端序
`little` · 每个16位字内，低字节在前

教学示例 `0x1234`：应用映射交换字节后为 **`34 12`**。

此设置对每个16位字分别交换两个字节，不改变多个寄存器的顺序。Modbus 单寄存器在线上传输仍按高字节先发。

Bool 不适用；其他类型应按设备手册确认映射方式。

## wordOrder.big
### 高字在前
`big` · 多寄存器从高位字到低位字

以下为 ESSim 教学映射示例，均按地址递增列出寄存器，且字节序为大端序：

- 32位 `0x12345678` → **`1234、5678`**。
- 64位 `0x1122334455667788` → **`1122、3344、5566、7788`**。

仅适用于32位／64位类型。Bool和16位类型不适用，固定保留 `big`。多寄存器字序按设备手册确定。

## wordOrder.little
### 低字在前
`little` · 多寄存器从低位字到高位字

以下为 ESSim 教学映射示例，均按地址递增列出寄存器，且字节序为大端序：

- 32位 `0x12345678` → **`5678、1234`**。
- 64位 `0x1122334455667788` → **`7788、5566、3344、1122`**。

64位会将四个16位字全部倒序，不只交换两组32位块；每个字内部的字节顺序仍由字节序决定。

仅适用于32位／64位类型；多寄存器字序按设备手册确定。
