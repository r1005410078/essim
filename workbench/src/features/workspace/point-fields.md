## name
**点名**用于显示，可以重复。系统使用稳定点 ID 识别点，改名不会改变身份。

## category
**四遥分类**按用途组织同一张点表：遥测读数值、遥信看状态、遥控发动作、遥调设参数。

修改分类后，点显示到对应底部 Tab，其他配置和身份不变。

## area
**数据区**决定协议访问方式。

| 数据区 | 地址对象 | 主站访问 |
|---|---|---|
| holding | 16 位寄存器 | 可读写，写入受从站权限限制 |
| input | 16 位寄存器 | 只读 |
| coil | 单个位 | 可读写，写入受从站权限限制 |
| discrete | 单个位 | 只读 |

遥控／遥调须使用 `holding` 或 `coil`。四遥不是四区的一一对应。

## address
**零基地址**范围为 `0～65535`，不是设备手册中的 `4xxxx` 展示编号。

例如 Float32 从地址 `100` 开始，占用 `100、101`。同一数据区不能重叠，校验会跨四遥分类检查。

## valueType
**类型**决定数值解释和地址占用。

- Bool：1 个位地址，只用于 coil／discrete。
- Int16／Uint16：1 个寄存器。
- Int32／Uint32／Float32：2 个寄存器。
- Int64／Uint64／Float64：4 个寄存器。

浮点使用 IEEE 754。字符串和寄存器内位拆分暂不支持。

## byteOrder
**字节序**控制每个 16 位字内部的两个字节。默认 `big`，高字节在前。

例如 `0x1234`：big 为 `12 34`，little 为 `34 12`。这是应用数值映射，不改变 Modbus 单寄存器线上高字节先发的规则。

Bool 不适用，使用 big。

## wordOrder
**字序**控制多个 16 位寄存器的排列。默认 `big`，高字在前。

| 32 位示例 `0x12345678` | 寄存器排列 |
|---|---|
| big | `1234、5678` |
| little | `5678、1234` |

64 位 little 会将四个 16 位字全部倒序，不只交换两组 32 位块。Bool 和 16 位类型不适用，使用 big。

## scale
**倍率**用于 `工程值 = 原始值 × 倍率`，默认 `1`。

支持有限负倍率，禁止 0、NaN 和无穷大。Bool 固定为 1。

例如原始值 `1250`、倍率 `0.1`，工程值为 `125.0`。整数反算不整除时报错，不会自动舍入或截断。精确值以文本传递。

## unit
**单位**只用于解释工程值，例如 `V`、`kW`。填写单位不会自动换算数值。

## initialEngineering
**初始工程值**由核心按倍率反算原始值；右侧显示实际编码结果。

整数须精确可表示，浮点允许目标精度的正常舍入，溢出时报错。Bool 输入 `true`／`false`。

这是模型初值，不是实例当前采集值，保存不自动影响模拟器。

## slaveWritable
**允许外部写入**是从站接收 holding／coil 写请求的权限，新建点默认 `true`；input／discrete 为只读区，不允许外部写入。

input／discrete 必须为 false。从站本地采集置数与外部写权限分开；这个字段不代表主站已取得远端写入权限。

## masterPeriodMs
**默认采集周期**是主站建议轮询间隔，单位毫秒，必须为正整数。

从站不使用这个字段。当前配置不会自动启动采集任务。

## note
**备注**记录点的业务含义或来源提示，不影响协议编码。

## width
**占用长度**由类型自动计算，只读。单位为寄存器数量，Bool 为位地址数量，不是程序内存占用。

## raw
**原始值预览**由 Rust 核心根据工程值、倍率和类型计算，保留 64 位整数精度。

预览不会发送通信、修改运行值或保存模型。
